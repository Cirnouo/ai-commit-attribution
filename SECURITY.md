# Security policy

Version 0.1.0 is under development. There are no published supported releases.
Reports about current development commits are welcome.

Use [GitHub private vulnerability reporting](https://github.com/Cirnouo/ai-commit-attribution/security/advisories/new)
for suspected vulnerabilities. Include the affected commit, operating system,
Node/Git/Agent versions, reproduction, expected and actual behavior, impact,
and required privileges. Remove tokens, private transcript content and secrets.
Avoid public exploit details before coordinated disclosure.

The maintainer will make a best effort to assess reports and coordinate fixes;
there is no guaranteed response deadline. Runtime boundaries are documented in
[the security policy](docs/policies/security.md), and dependency coverage and
limitations in [the supply-chain policy](docs/policies/supply-chain.md).
