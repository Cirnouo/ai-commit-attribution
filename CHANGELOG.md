# Changelog

All notable user-facing changes will be documented here, following
[Keep a Changelog](https://keepachangelog.com/en/1.1.0/) and

## [Unreleased]

Version 0.1.0 is in development. No runtime Skill has been released.

### Added

- A self-contained development Skill distribution with a researched host
  registry and read-only participation summary command. Summaries preserve
  event evidence, all declared/observed participant accounting, stable identity
  tuples, optional effort diagnostics and separately scoped user exceptions.
- Typed bug and feature reports with current-form validation and recoverable
  feedback, while preserving freeform Issues and private security reporting.

### Security

- Summary inputs reject raw control injection and incompatible supplied operation
  scopes. Exact generated payload inventories, license bytes and isolated
  business execution are checked without repairing drift; evidence declarations
  never authenticate dispatch, consent or permission to change Git state.
