### Added

- skills.sh installation for Codex, with a first-use landing page and user guide
  covering source and existing-copy use, policy outcomes and evidence gaps.
- Complete installed disclosure workflow, conditional host evidence and a human
  first-use guide for worktree-local planned-commit ledgers, explicit policy
  decisions and message inputs. Portable acceptance recipes distinguish
  copied-bundle and real-Git fixtures from native-host, question and fixed-source
  installation evidence.
- Message preview/render and read-only validation with exclusive policy routing,
  canonical default trailers and exact signature migration mappings. Confirmed
  identity sets preserve actual formal model punctuation and distinct optional
  reasoning values; known required gaps remain explicit blockers.
- Semantic policy review by the Agent for the actual worktree, operation and
  selected paths, with explicit repository-policy, skill-default and needs-decision
  decisions. Lightweight helpers check supplied scopes without discovering
  documents or treating declarations as verified policy or live state.
- One durable ledger per planned output commit, with explicit current selection,
  pause/recovery, independent overlapping participant sets and split/combine
  allocation. Preparation freezes a candidate and complete staged result plan;
  finish reconciles the exact full commit SHA, ordered parents, tree and final
  message while retaining immutable history and idempotent completion.
- Explicit export, resume/copy import, original-move rebind and removal checks
  for ignored worktree-local state, including recovery of interrupted transfers
  and prepared results after the source worktree disappears.
- A self-contained development Skill distribution with a researched host
  registry and read-only confirmed-participation summary command.
- Typed bug and feature reports with current-form validation and recoverable
  feedback, while preserving freeform Issues and private security reporting.

### Security

- Trailer processing isolates Git configuration and preserves unrelated message
  bytes. Explicit output creates only a separate absent safe file; blockers and
  failures never overwrite inputs or change Git state/identity.
- Repository policy routing bypasses default identity, blocker, registry and
  assessment checks. The Agent owns semantic policy review and freshness;
  bounded read-only Git observation compares complete staged/result evidence
  without executing repository policy scripts or creating commits.
- Local state uses explicit versions, short locks, compare-and-swap and safe
  publication. Interrupted candidate, state and transfer writes retain artifacts
  for recovery; helpers never rewrite history or change Git identity.
- Inputs reject raw control injection and incompatible scopes. Exact generated
  payload inventories, license bytes and isolated business execution are checked
  without repairing drift. Declarations, preparation receipts and offline
  transfers never authenticate participation, consent, global ownership or
  permission to perform a Git action.
