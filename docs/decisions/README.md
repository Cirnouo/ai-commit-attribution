# Architecture decisions

[0001-summary-evidence.md](0001-summary-evidence.md) records the historical
schema-1 event, supplied-scope and installed summary distribution boundary.
Its staged command inventory is historical; 0005 partially succeeds its
participation model while retaining Operation/registry schema 1 and distribution.
[0002-policy-routing.md](0002-policy-routing.md) preserves the superseded scanner,
candidate, binding and automatic freshness design.
[0003-message-attribution.md](0003-message-attribution.md) records isolated trailer
interpretation, byte-span preservation, exclusive message routing and historical
scoped exception applications. 0004 supersedes its scan associations and
stale-routing requirements; 0005 accepts replacement of event joins and exception
continuation while retaining trailer, preservation and signature safeguards.
[0004-agent-policy-discovery.md](0004-agent-policy-discovery.md) records the current
Agent semantic-discovery boundary, schema-2 policy decisions and the delivered
schema-2 message assessments/minimal Git-directory lookup at base `a1b0499`.
0005 preserves semantic discovery and exclusive routing while accepting new
message schemas and a dedicated read-only result observer.
[0005-planned-commit-ledgers.md](0005-planned-commit-ledgers.md) accepts the
forward planned-commit ledger, worktree ownership, explicit preparation/result
and transfer design. It partially succeeds 0001, 0003 and 0004; its new schemas
and lifecycle are not implementation or verification claims at base `a1b0499`.

Decisions explain durable design choices and preserve their historical context.
Installed instructions in [packaging](../../packaging/README.md) own runtime
behavior; contributor policies remain in [docs/policies](../policies/README.md).
