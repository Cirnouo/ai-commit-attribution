# Policies

- [Commits and scope](commits-and-scope.md): branches, messages, current PR submission and typed Issues.
- [Documentation](documentation.md): ownership, directory navigation and instruction disclosure.
- [Quality](quality.md): toolchain, YAML naming, checks, hooks and platform setup.
- [Supply chain](supply-chain.md): preinstall trust, full audit coverage and bounded exceptions.
- [Security](security.md): runtime and governance security invariants.
- [Releases](releases.md): versions, Changelog baseline and separately authorized publication.
- [Migration](migration.md): exact source adoption, adaptations and exclusions.
- `security-exceptions.json`: machine-readable, human-reviewed bounded exceptions; initially empty.
