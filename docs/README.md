# Documentation

The [policies directory](policies/README.md) owns contributor obligations,
verification, security, release authorization and the reference migration record.
platform-settings.json records dated live GitHub observations separately from
the historical source-policy baseline; final required contexts follow CI success.
The root README introduces the product; CONTRIBUTING explains contribution setup.
User runtime instructions are maintained in packaging/ and generated into the
complete skills/ai-commit-attribution/ payload, separately from repository governance.
The [summary architecture decision](decisions/0001-summary-evidence.md) records
the supplied-operation/evidence boundary and current distribution design.
The [acceptance guide](acceptance/README.md) owns the portable scenario corpus,
reproduction commands, eighteen-requirement evidence map and native-host limits.
