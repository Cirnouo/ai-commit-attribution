# Attribution runtime

records.ts owns schema validation and shared supplied-scope canonicalization.
summarize.ts resolves same-event declared evidence, participant accounting and
stable identity tuples. attribution.ts exposes summarize and policy scan, and
locates its installed registry from import.meta.url. Source requires no runtime packages.

The maintained installed contracts are packaging/records.md and packaging/policy.md.
policy-contract.ts owns strict scan/context/decision/route shapes and limits.
policy-scope.ts owns deterministic binding serialization and live Git/path
observation through safe-git.ts. policy-evidence.ts owns bounded discovery and
safe evidence; policy.ts joins Agent semantic decisions to a fresh capture.
policy-markdown.ts owns the finite prose format profile and bounded lexical
inline-link extraction without reading files or interpreting policy meaning.
checkFreshRouting retains its exact freshScan for internal downstream evidence
joins; attribution.ts omits that internal member from public route JSON.
Policy paths never import default summary or read the installed registry.
message.ts adds route-first render/validate with a lazy default-input boundary.
message-contract.ts owns their result types; message-assessment.ts checks exact
current signature/migration/exception joins. message-trailers.ts runs isolated
Git interpretation and reconciles owned byte spans. message-output.ts creates
only safe absent new files. packaging/messages.md owns the installed contract.
The observation-only SafeGit argv allowlist does not include trailer processing.
