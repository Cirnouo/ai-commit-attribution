# Summary runtime

records.ts owns schema validation and shared supplied-scope canonicalization.
summarize.ts resolves same-event declared evidence, participant accounting and
stable identity tuples. attribution.ts exposes only summarize and locates its
installed registry from import.meta.url. Source requires no runtime packages.

The maintained installed contract is packaging/records.md. The command does not
capture live Git state, choose disclosure policy, render trailers or validate
messages; those responsibilities are introduced in later feature changes.
